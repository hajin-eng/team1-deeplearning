# 다이캐스팅 불량 유형 예측 — 팀 new1

포스코 K-뉴딜아카데미 딥러닝 1기 최종 프로젝트입니다. 샷마다 남는 공정·센서 기록(7,535샷 × 32열)만으로 불량 유형 7종(정상, Short_Shot, Blow_Hole, Exfoliation, Stain, Deformation, 기타불량)을 미리 예측합니다. 지표는 macro F1입니다.

- 최종 제출안(1안): 랜덤포레스트 + ExtraTrees 확률 평균 + 두 단계(불량 여부 → 불량 종류) 혼합 + 앞뒤 사건 입력 40개 추가. 중간 리더보드(public) 점수 **0.5987**(공개 기준선 0.2517).
- 현장성을 높인 또 다른 안(2안): 랜덤포레스트 2개 평균, 입력 25개. 중간 리더보드(public) 점수 0.5710.

## 팀 · 역할

팀장: 오정수

| 팀원 | 주 담당 |
|---|---|
| 강문주 | 1안 전처리, 1안 모델링, 시각화(html) 제작, 기획서 제작 |
| 오정수 (팀장) | 2안 모델링, 발표 |
| 김지수 | 보고서, ppt·발표 자료 제작 |
| 김다한 | 2안 전처리, 보고서 작성 |
| 김하진 | 데이터 메모, 깃허브 관리 |

## 실행 방법

```bash
cd 최종프로젝트_학생배포
pip install -r requirements.txt
python main.py
```

- 결과 파일: `최종프로젝트_학생배포/제출_new1.csv` (2,261행, 컬럼 `shot_id,label`)
- 상대경로만 쓰고 시드(42)를 고정했습니다. CPU로 약 80초 걸립니다. 실행 중 CPU 코어를 모두 쓰므로 여유 메모리가 부족하면 학습이 멈출 수 있습니다.
- 경보 기준은 `main.py` 위쪽 설정의 `ALERT_NORMAL_SCALE` 한 줄로 바꿉니다(1.0 = 제출 기준, 작게 하면 불량을 더 자주 부름). 바꿔 돌릴 때는 `TEAM_NAME`도 바꿔야 제출 파일을 덮어쓰지 않습니다.
