2. 문제 정의

  • 누가 곤란한가: 품질 담당자는 금형을 열어 검사한 뒤에야 불량을 안다. 그때는 재료·시간·설비 가동이 이미 들어간 뒤다.
  • 무엇을 바꾸나: 샷마다 남는 공정·센서 기록(7,535샷 × 32열)만으로 불량 유형을 미리 예측한다. 선별은 불량 가능성이 높은 샷을 먼저 걸러 검사 부담을 줄이는 것, 예방은 불량을 늘리는 공정 조건을 찾아 미리 조정하는 것이다.
  • 맞힐 라벨 7종: 정상 / Short_Shot(미충전) / Blow_Hole(기공) / Exfoliation(박리) / Stain(얼룩) / Deformation(변형) / 기타불량. 정상이 77.6%라 정확도는 의미가 없고 지표는 macro F1이다.
  • 두 가지 안: 1안(최종 제출안)은 리더보드 점수를 높이는 모델이고, 2안(현장성을 높인 또 다른 안)은 입력 25개만 써서 실시간 판정이 되는 현장 후보 모델이다.

5. 접근 방법

  • 기준 모델: 로지스틱(class_weight, 공개 기준선 0.2517)과 랜덤포레스트로 기준선을 만들고, 10/16 첫 제출로 파이프라인을 확인했다.
  • MLP: 입력 25 → 은닉 128 → 64 → 출력 7, ReLU, 드롭아웃 0.2, 클래스 가중 교차엔트로피, Adam 1e-3, 검증 손실이 최저인 epoch 18에서 멈춤. 리더보드 구조에서는 0.289로 트리(0.58대)보다 낮았는데, 시험의 58%가 학습에 같은 입력이 있어 트리는 외우고 MLP는 못 외우기 때문이다(새 입력만 보면 0.277 대 0.279로 같다).
  • 비교 실험 3종(한 번에 하나만 변경): ① 앞뒤 사건 입력값 추가 +0.0045(채택), ② 클래스 가중치 강도 0.3 / 0.75 / 1.0 → 모두 노이즈 수준(0.5 유지), ③ 잎 크기 1 → 2 → 0.608 vs 0.610(동일).
  • 1안(최종 제출안): 랜덤포레스트 + ExtraTrees 확률 평균 + 두 단계(불량 여부 → 불량 종류) 혼합 + 앞뒤 사건 입력 40개(입력 25 → 65개). 뒤 사건 입력이 필요해 사후 분석·일괄 선별용이다. 2안(현장성을 높인 또 다른 안): 랜덤포레스트 2개 평균, 입력 25개로 실시간 판정이 된다.
  • 검증 방법: 무작위 80/20, 시간순 80/20에 더해 쌍둥이를 같은 쪽에 둔 5분할(새 입력)과 연속 100샷을 떼는 5분할(새 생산 구간)을 쟀다. 학습곡선은 epoch 곡선과 데이터 20~100% 곡선 2종이다.
  • 모델 선택: 10/15 계획은 "public 점수로 고르지 않는다"였으나, 실제로는 public 점수가 높은 1안(0.5987 대 0.5710)을 최종으로 정했다. 차이 0.028은 표본 흔들림(SD 0.037) 안이라 학습 데이터 검증으로 확인했고(무작위 1안 0.560 대 2안 0.504), 새 입력에서는 순위가 뒤집힘(0.258 대 0.323)을 한계로 밝혔다.
  • 운영 기준(Q2): 놓침 1건 = 헛경보 5·10·20건으로 가정한 비용표로 운영안을 골랐다. 제출 CSV(정상 ×1.0, macro F1용)와 운영안(정상 ×0.1, 놓침 비용용)은 목적이 달라 분리했고, 두 모델의 최저 비용 차이는 4% 안이다. 원인 분석(Q3): 불량 종류별 RF의 순열 중요도로 조건을 뽑아 구간별 불량률을 직접 세고, 인과가 아닌 관리 후보로만 쓴다.
