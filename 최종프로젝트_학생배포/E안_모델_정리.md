### 2-3. 데이터에서 찾은 문제와 처리
| 문제 | 처리 | 근거 |
|---|---|---|
| CSV 헤더가 2줄, 열 이름에 공백, 파일 앞에 BOM | `header=1`, `strip()`, `utf-8-sig`로 읽음 | 안 하면 열을 못 찾음 |
| 값이 하나뿐인 열 8개. 공장 온도·습도의 Min/Max(18~22)는 실측(온도 27~37, 습도 45~72)과도 안 맞음 | 제거, 측정값은 그대로 | 정상과 불량을 구분할 정보가 없음 |
| 공장 온도·습도 결측 90행 (전부 Type 2, 두 덩어리) | 덩어리 앞뒤 실측값 30개씩의 중앙값으로 채우고 `factory_missing` 표시 | 행을 지우면 test 27행이 빠져 실격. 채우는 방식을 바꿔도 점수 차이 없음(RF 0.231~0.235) |
| 속도 0 (4샷), 비스킷 두께 0 (4샷), 사이클 60초 초과 (11샷) | 값을 고치거나 지우지 않고 표시 열만 추가 | 설비 정지로 보이는 사실 정보. 지워도 점수 차이가 표준편차 안쪽 |
| **같은 입력의 행이 2~4개씩 반복 (쌍둥이)** | 행은 그대로 두고 그룹 번호만 붙여 검증 분할에서만 사용 (train 그룹 3,663개) | 쌍둥이 안의 라벨 일치율 97.8%. 무작위로 나누면 점수가 부풀려짐 |
| 정상이 77.6%인 클래스 불균형 | 모델의 클래스 가중치로 처리 | 가중치가 없으면 거의 전부 "정상"이라고 답함(0.126) |
| 불량이 제품·시기에 몰림 | `Product_Type` 열을 그대로 사용, 제품별 모델은 만들지 않음 | 원인 해석에서는 시기·제품 차이와 구분해야 함 |
| `Shot` 번호가 중간에 1로 리셋 | 식별 열이라 특징에서 제외 | 규칙상 특징으로 쓰면 실격 |
| 열마다 크기가 크게 다름 (주조압 516~1,164 vs 속도 0.13~0.2) | 스케일링 안 함 | RF는 크고 작음만 봐서 필요 없음 |
| 환경 열(공장 온도·습도, 공기압, 냉각수)이 "시기 표지"로 추정됨 | 유지 | 빼면 점수 하락(RF 0.3248 → 0.2863, 잎 10·시드 42). 중요도가 높아도 원인으로 해석하지 않음 |

- 원본 불량 기록 파일(`참고_원본불량기록_train.csv`)은 규칙상 특징·라벨로 쓸 수 없어서 모델에 쓰지 않았습니다.

## 3. E안은 어떤 방식인가

### 3-1. 문제의 종류와 모델 선택
- 샷 하나의 기록으로 7개 라벨 중 하나를 고르는 **분류** 문제입니다. 회귀 모델은 쓰지 않았습니다(로지스틱 "회귀"도 이름만 회귀이고 하는 일은 분류).
- 같은 전처리·같은 쌍둥이 그룹 5조각·시드 4개 평균으로 비교했습니다.

| 모델 | 그룹 CV | 특징 |
|---|---|---|
| 로지스틱 회귀 | 0.2874 | 직선으로만 가르는 모델이라 학습 데이터조차 0.24밖에 못 맞힘(과소적합) |
| HGB 설정 B | 0.3050 | 앞 나무의 오답을 차례로 고치는 부스팅. 정상을 불량으로 잘못 부르는 경우가 많음 |
| **RF (잎 10, 강도 0.5)** | **0.3255** | 시드 4개 모두 HGB보다 높음 |

- 같은 값이 반복되는 열이 많고 "A가 이하이고 B가 이하일 때" 같은 조건 조합이 필요해서 트리 모델이 맞습니다. 스케일링이 필요 없고 극단값(사이클 218.6)에도 덜 흔들립니다.

### 3-2. 랜덤포레스트가 하는 일
- "형체력이 367 이하인가?" 같은 질문을 이어서 샷을 나누는 나무(스무고개)를 서로 조금씩 다른 데이터로 300그루 키우고, 300그루의 결과를 평균내서 확률이 가장 큰 라벨을 고릅니다.
- **E안 설정의 의미**
  - **잎 최소 1샷:** 나무 끝에 샷이 한 개만 있어도 결론을 냅니다. 즉 샷 하나하나까지 쪼개서 사실상 학습 데이터를 외웁니다. 실제로 학습 데이터에 대한 macro F1은 0.969인데, 처음 보는 입력(그룹 CV)에서는 0.295입니다.
  - **열 sqrt:** 질문 하나를 고를 때 25개 열 중 5개만 무작위로 보여 줍니다.
- 그 결과 test 행과 입력이 똑같은 train 행(쌍둥이)이 있으면 그 행의 라벨을 거의 그대로 냅니다. 별도 조회 코드는 없습니다.

### 3-3. 클래스 가중치 (강도 0.5)
| 클래스 | 샷 수 | 가중치 |
|---|---|---|
| 정상 | 4,092 | 0.429 |
| 불량_Short_Shot | 469 | 1.267 |
| 불량_Blow_Hole | 233 | 1.798 |
| 불량_Exfoliation | 198 | 1.951 |
| 불량_Deformation | 106 | 2.666 |
| 불량_Stain | 100 | 2.745 |
| 기타불량 | 76 | 3.149 |

- 기타불량 1개를 틀리면 정상 1개를 틀릴 때의 7.3배 벌점입니다. balanced 그대로면 54배라서 정상의 77%를 불량이라고 불렀습니다.
- 가중치는 교차검증 조각마다 그 조각의 학습용 정답만으로 계산합니다(검증 정보 유출 방지).

### 3-4. 학습과 검증 순서
1. `load_data()`로 전처리를 받는다.
2. 쌍둥이 그룹 5조각 교차검증: 쌍둥이는 같은 조각에, 클래스 비율은 조각마다 같게.
3. 5조각의 예측을 합쳐서 macro F1을 한 번에 계산한다.
4. 제출용 모델은 train 5,274행 전체로 다시 학습해서 test 2,261행을 예측한다.
5. 제출 형식(2,261행, `shot_id,label`, `shot_id` 순서, 라벨 7종)을 자동 검사하고 저장한다.

## 4. 결과

### 4-1. 점수 (같은 E안, 세 가지 방식으로 잰 값)
| 검증 방식 | 점수 | 뜻 |
|---|---|---|
| 랜덤 분할 CV (시드 42·0) | 0.545 | 쌍둥이가 갈라져서 외운 효과가 섞임 |
| **리더보드풍** (랜덤 CV를 쌍둥이 58% 가정으로 가중) | **0.590** | test 구조를 흉내 낸 어림 |
| 쌍둥이 그룹 분할 CV (시드 4개) | 0.2951 ± 0.0033 | 처음 보는 입력에서의 성능 |
| 블록 CV (연속 구간 단위, 경계 15샷 비움) | 0.1732 | 새로운 시기의 샷에서의 성능 (가장 정직) |
| **실제 public 채점** | **0.5853** | 강사 채점 |

- 분할이 정직할수록 점수가 낮아지는 것이 핵심입니다.
- 어림(리더보드풍)이 실제와 맞았습니다: 1회차는 어림 0.383 → 실제 0.4089, E안은 어림 0.585(public 쌍둥이 비율 57.1% 사용) → 실제 0.5853.

### 4-2. 점수가 어디서 나오나 (랜덤 CV, 시드 42)
| 구분 | 행 수 | 정확도 | 불량을 유형까지 맞힌 비율 |
|---|---|---|---|
| 쌍둥이가 학습에 있는 행 | 2,568 | **0.953** | **90.5%** |
| 쌍둥이가 없는 행 | 2,706 | 0.725 | 17.2% |

- 쌍둥이가 있는 행의 macro F1은 0.80, 없는 행은 0.28~0.30입니다.
- test의 약 58%가 쌍둥이 행이라서 전체 점수가 높게 나옵니다. 점수를 더 올릴 곳은 쌍둥이가 없는 행입니다.

### 4-3. 현장 말로 옮기면 (쌍둥이 그룹 CV, 시드 42)
- 불량 1,182샷 중 **330샷(27.9%)을 "불량 중 하나"로 알렸고**, 유형까지 정확히 맞힌 것은 188샷(15.9%)입니다.
- 정상 4,092샷 중 **393샷(9.6%)을 불량이라고 잘못 알렸습니다.**
- 이 수치는 쌍둥이가 없는 새 샷에서의 성능이라 점수(0.5853)보다 훨씬 낮습니다.

### 4-4. 클래스별 성적 (쌍둥이 그룹 CV, 시드 42)
| 클래스 | 샷 수 | precision | recall | F1 |
|---|---|---|---|---|
| 정상 | 4,092 | 0.813 | 0.904 | 0.856 |
| 불량_Short_Shot | 469 | 0.213 | 0.100 | 0.136 |
| 불량_Blow_Hole | 233 | 0.344 | 0.227 | 0.274 |
| 불량_Exfoliation | 198 | 0.247 | 0.111 | 0.153 |
| 불량_Stain | 100 | 0.267 | 0.310 | 0.287 |
| 불량_Deformation | 106 | 0.271 | 0.302 | 0.286 |
| 기타불량 | 76 | 0.130 | 0.039 | 0.061 |

- 정상은 잘 가려내지만 Short_Shot, Exfoliation, 기타불량은 거의 못 잡습니다.
- 약점: Short_Shot을 제품별로 보면 Type 1에서는 실제 161개 중 **3개(1.9%)**만 맞히고, Type 2에서는 308개 중 44개(14.3%)를 맞힙니다. 특히 Type 1의 Short_Shot을 거의 못 잡습니다(그룹 CV, 시드 42).
